# Fuentes (no incluidas en el repositorio)

Louize Display (205TF) y Beausite Classic (Fatype) son fuentes comerciales.
Sus archivos no se publican aquí; colócalos en esta carpeta con licencia web:

- `louize-display.woff2` → titulares, menú y botones
- `beausite-classic.woff2` → columnas del footer

Sin ellos, el sitio usa los respaldos definidos en `src/styles/tokens.css`
(Times New Roman y Hanken Grotesk). Ver `src/styles/fonts.css`.
